# Documentation boundary

Owns contributor commands, product sources, accepted decisions and technical plans. `decisions/` holds accepted durable constraints; implementation plans describe technical scope and phase files own acceptance truth. Disposable verification logs and review captures are stored outside the repository and linked from delivery work items.

Start with [developer setup](developer-setup.md), [project status](../PROJECT_STATUS.md) and [P01 criteria](../Phases/P01-repository-and-developer-foundation.md). Never infer completion from a generated artifact or a green provider build.
