# Former development workflow — superseded

The former Jira development workflow is retired by [Decision 0008](decisions/0008-checkpoint-development-workflow.md), dated 10 November 2026. Use the [checkpoint development workflow](DEVELOPMENT_WORKFLOW.md). No Jira development administration, connection, naming, validation or linkage is required. This historical path is retained for existing references; it contains no active setup procedure. Customer-facing Jira product integration remains in scope.
