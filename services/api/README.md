# Canonical API boundary

Owns canonical APIs, authorization, integrations and orchestration. Public local diagnostic exceptions expose no customer data: `GET /foundation`, `GET /api/v1/version`, `GET /health/live`, `GET /health/ready`, `/docs` and `/openapi.json`. Domain authorization arrives in P02; no permissive authorization middleware is installed. Do not expose this local profile as a secured deployment.

From the root: `uv sync --frozen --all-packages --all-groups`; `uv build --package shipsense-api`; `uv run --frozen --package shipsense-api uvicorn shipsense_api.main:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log`. Inspect `/api/v1/version`, `/health/live`, `/health/ready`, `/docs` and `/openapi.json`. No credentials or backing service are required. `SHIPSENSE_PROFILE` defaults to `local`; any other profile fails startup without exposing its value. Stop with Ctrl+C. Disable raw Uvicorn access logging as shown: it otherwise includes untrusted URLs/query values. Application diagnostic logs contain only generated/validated request IDs and status codes.

Version is the fixed bounded release identifier `0.1.0-dev`; `observedAt` is fresh UTC per request. All responses use `Cache-Control: no-store` and `X-Request-ID`. Supply one optional `X-Request-ID` of 1–64 ASCII letters, digits, underscores or hyphens; invalid/duplicate values return safe 422 with a fresh generated reference. Unexpected exceptions return safe 500. Rejected values, exception text and dependency addresses never appear in the error envelope. OpenAPI contains the custom 422/500 models/examples, version success and readiness 503 examples.

Liveness reports only process availability. Readiness returns 503 `DEPENDENCY_UNAVAILABLE` by default because no MongoDB/storage/queue adapters are installed. `ReadinessGate` accepts exactly those three named asynchronous probes, each with a one-second timeout within a three-second overall deadline and four concurrent request slots; excess requests fail closed. Probes must be nonblocking and cooperate with cancellation; their adapters own connection pools and shutdown. No shared success cache is used. Unit probes verify interface behavior only. Real adapter startup, outage and recovery proof remains required with SCRUM-15 before full SCRUM-16 acceptance; this slice cannot report real dependency health.

Run `npm run test:foundation` for local diagnostic, unsupported profile and fixture failure tests. Run `npm run contracts:generate` to publish the canonical schema and generated TypeScript. No migrations or persistence exist in this slice.
